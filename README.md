# AI-помощник туриста для Нижнего Новгорода

Telegram-бот для создания персонализированных маршрутов прогулок по Нижнему Новгороду с использованием GigaChat AI и 2ГИС API.

**🎮 Демо-версия:** [@SenseiGift_Bot](https://t.me/SenseiGift_Bot)

**📄 Описание проекта:** [Документация](https://docs.google.com/document/d/1QWqFJwaWPLfo3jucNN-9Xbnd1gYgNHOp/edit?usp=drivesdk&ouid=104269739819607935342&rtpof=true&sd=true)

## 🎯 Возможности

- **Умный анализ интересов** — GigaChat понимает намерения пользователя (кофейни, музеи, набережные и др.)
- **Персонализированные маршруты** — генерация маршрутов из 3-5 мест с уникальными описаниями
- **Оптимальное планирование** — учет времени прогулки и расстояний между местами
- **Интеграция с картами** — визуализация маршрута через 2ГИС
- **Автоматическая коррекция адресов** — исправление опечаток в названиях улиц

## 🚀 Быстрый старт

### 1. Требования

- Python 3.14+
- Telegram Bot Token ([получить у @BotFather](https://t.me/BotFather))
- GigaChat API Key
- 2ГИС API Key (опционально, есть дефолтный ключ)

### 2. Установка

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd super-trainer

# Создайте виртуальное окружение
python3.14 -m venv venv

# Активируйте виртуальное окружение
# macOS/Linux:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt
```

### 3. Настройка

Создайте файл `.env` в корне проекта:

```env
TELEGRAM_BOT_TOKEN=ваш_telegram_bot_token
GIGACHAT_API_KEY=ваш_gigachat_api_key
GIGACHAT_BASE_URL=https://foundation-models.api.cloud.ru/v1
GIGACHAT_MODEL=GigaChat/GigaChat-2-Max
DVGIS_API_KEY=ваш_2gis_api_key
DATASET_PATH=data/cultural_objects_mnn.xlsx
```

**Обязательные переменные:**
- `TELEGRAM_BOT_TOKEN` — обязателен
- `GIGACHAT_API_KEY` — обязателен

**Опциональные переменные (если не указаны, используются значения по умолчанию):**
- `GIGACHAT_BASE_URL` — по умолчанию: `https://foundation-models.api.cloud.ru/v1`
- `GIGACHAT_MODEL` — по умолчанию: `GigaChat/GigaChat-2-Max`
- `DVGIS_API_KEY` — опционально (некоторые функции могут не работать)
- `DATASET_PATH` — по умолчанию: `data/cultural_objects_mnn.xlsx`

### 4. Запуск

```bash
python main.py
```

Бот будет доступен в Telegram. Отправьте команду `/start` для начала работы.

## 🏗️ Архитектура

### Основные компоненты

1. **GigaChatService** — анализ интересов пользователя и генерация маршрутов с описаниями
2. **Maps2GISService** — геокодирование адресов, поиск мест и построение маршрутов
3. **DatasetService** — загрузка и фильтрация культурных объектов из Excel
4. **RouteGenerator** — оркестрация всех сервисов для создания финального маршрута
5. **Telegram Bot Handlers** — обработка команд и сообщений через FSM

### Процесс работы

```
Пользователь → /start
    ↓
Бот задает вопросы:
  1. Интересы (текст/кнопки)
  2. Время прогулки
  3. Начальная точка (адрес/геолокация)
    ↓
GigaChat анализирует интересы → определяет intent и категории
    ↓
Поиск мест:
  - Датасет культурных объектов
  - 2ГИС API (если нужно)
    ↓
Фильтрация и сортировка:
  - По расстоянию от пользователя
  - По рейтингу (мин. 4.1)
  - По количеству отзывов
    ↓
Построение оптимального маршрута:
  - Ближайшие места к пользователю
  - Минимальные расстояния между местами
  - Гарантированный минимум 3 места
    ↓
GigaChat генерирует маршрут с уникальными описаниями
    ↓
Форматирование и отправка пользователю
```

## 📝 Использование

1. Откройте бота в Telegram
2. Отправьте `/start`
3. Следуйте инструкциям:
   - Укажите интересы (например: "кофейни", "набережные", "музеи искусств")
   - Выберите время на прогулку (в часах)
   - Укажите начальную точку (адрес или отправьте геолокацию)
4. Получите персонализированный маршрут с описаниями и картой!


## 📊 Датасет

Проект использует датасет культурных объектов Нижнего Новгорода из приложения "Мой Нижний Новгород".

**Формат данных:**
- `id` — идентификатор объекта
- `title` — название
- `address` — адрес
- `coordinate` — координаты в формате POINT
- `description` — описание (HTML)
- `category_id` — категория
